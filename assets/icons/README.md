# Glifos de enlaces sociales

Fuente: [Bootstrap Icons](https://github.com/twbs/icons), commit `829d2bc2b87543c7d781c815ca4f0feee8cf9e45`.

Se incluyen únicamente linkedin.svg, instagram.svg y envelope.svg, conservando sus trazados originales. Licencia MIT y aviso de copyright: [LICENSE-bootstrap-icons.txt](LICENSE-bootstrap-icons.txt).

Los botones que los contienen son composiciones propias, con colores de S3rri y texto visible. Los SVG no consultan servicios externos; el enlace pertenece al HTML del README y cuenta con nombre accesible. Regeneración: [render_social_links.py](../../scripts/render_social_links.py).
